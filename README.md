Aglet Movie App

Overview

This project was developed as part of the Aglet technical assessment.
The application integrates with The Movie Database (TMDb) API to display popular movies and allows authenticated users to manage their favourite movies.

-------------------------------------

Features

- User authentication
- Display popular movies from TMDb
- Responsive Bootstrap interface
- Pagination
- Add movies to favourites
- Remove favourites
- Contact page
- MySQL database integration

-------------------------------------

Technologies

- PHP 8
- MySQL
- Bootstrap 5
- HTML5
- CSS3
- JavaScript
- TMDb API
- XAMPP

-------------------------------------

Installation

Requirements

- PHP 8+
- MySQL
- XAMPP

Setup

1. Clone the repository

git clone https://github.com/reetsangkekana/aglet-movie-app.git

2. Copy the project into:

xampp/htdocs/

3. Start Apache and MySQL in XAMPP.

4. Import the provided database:

database.sql

5. Open:

http://localhost/aglet-movie-app/
